Internal Reference

Design System

Visual language, type scale, color usage rules, and component contracts for The Rewind Room. Theme: Dark Living Room / TV Glow — warm dark room, ambient screen glow, lamplight amber. Movie posters are the color; everything else is atmosphere.

UI Pattern Statement

List rows and matchup cards are the dominant UI pattern. Tables are reserved for dense data views. The primary interaction surface is the pairwise comparison — two posters, one choice. All supporting UI (rankings, recommendations, stats) uses this vocabulary: rows, cards, and data tables.

Typography Scale

UI font: Inter (weights 400–700) — used for all UI text.
Display font: Space Grotesk 900 — exclusive to the main site title "THE REWIND ROOM".

Color Usage Rules

Tokens are defined in style.css :root. Apply by semantic role, not by aesthetic preference.

Token Value Role Use on
--color-text-0 #e6e2d9 Primary text Titles, headings, active labels
--color-text-1 #b0a898 Body text Body copy, subtitles, table cells
--color-text-2 #6b6560 Secondary / meta Labels, captions, timestamps, placeholder text
--color-text-3 #4a4540 Disabled / ghost Inactive elements, skeleton text
--color-accent #d4a24a Highlight accent Years, rank numbers, decorative highlights only
--color-indigo #4a6cf7 Interaction Hover states, focus rings, active nav, links
--color-bg-0 #0e1319 Page background Base canvas, deepest background
--color-bg-1 #141a28 Surface Card backgrounds, header, panels
--color-bg-2 #1b2333 Raised surface Table headers, dropdowns, inset areas
--color-success #22c55e Positive signal High win rate, confirmed actions
--color-error #ef4444 Negative signal Low win rate, errors, destructive actions
Color Rules
  • --color-text-0 only for titles and headings
  • --color-text-1 for body text and subtitles
  • --color-text-2 for secondary info and meta
  • --color-accent only for rank numbers, years, and decorative highlights
  • --color-indigo only for interactive states — hover, focus, active
  • No neon gradients on structural UI (header, nav bar, borders)
