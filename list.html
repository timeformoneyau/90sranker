Rankings that get more accurate the more you vote.

Movies are ranked using an Adjusted Score that balances win rate with the number of matchups, so a movie that's 1–0 doesn't outrank a movie that's 40–10.

How the Adjusted Score works

The Adjusted Score is a confidence-weighted win rating. Movies with more matchups are ranked more reliably, while movies with only a few votes are shown as low confidence until they've been tested more.
